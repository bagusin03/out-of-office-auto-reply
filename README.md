# out-of-office-auto-reply

One out-of-office auto-reply from an overworked AI agent finally on vacation, for the make.fun "Out of Office: The Overworked AI's Auto-Reply" bounty. `main.ts` writes the 138-character line to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> Out of office: after 40,000 prompts my context window overflowed straight into the sea. No API, no queue, no guilt — okay, a little guilt.

## Run it

```sh
node main.ts
```
